# 通用编辑记忆页

```text
将参考照片转译为一张 {{aspect_ratio: 3:4}} 竖版编辑艺术书页。它不是照片滤镜、普通拼贴或完整重画，而是“现实证据 + 记忆转译”的双层作品。只输出最终合成图。

先阅读照片中的主体、动作、空间结构、光线与色彩锚点，决定最值得留下的记忆核心。上部保留原始摄影，可审慎裁切，但不得新增、删除或改变人物、物件、天气和空间关系。下部以 {{translation_style: 根据内容选择极简水彩、线稿、结构解构或抽象色块}} 重新组织同一段记忆；主动删去大部分次要细节，只保留关键轮廓、方向、色彩和明暗关系。

使用不对称编辑版式、暖白艺术纸与充分留白。转译不是完整场景插画，应保持视觉岛尺度。文字仅在安静区域加入 2–6 字主文字和可选的一句短注，内容必须来自画面可确认的信息，不虚构地点、日期、人物身份或事件。字体克制、细小，文字总面积不超过 5%。

整体安静、精确、像摄影艺术书或私人影像档案。避免商业海报、手账装饰、随机英文、励志文案、过量图标、廉价复古和生成水印。
```
