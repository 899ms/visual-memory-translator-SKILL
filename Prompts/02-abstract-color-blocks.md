# 上下抽象色块转译

```text
将参考照片转译为一张 3:4 竖版编辑艺术书页，采用上下布局。只输出最终合成图。

上部保留真实摄影，由 AI 选择最能体现主体、空间和色彩关系的裁切，不改变人物、物件和环境事实。下部不用滤镜或写实重画，而以少量大小悬殊的抽象色块重组同一画面：提取 2–4 种低饱和主色与一个必要强调色，用位置、比例、方向、负形和透明叠印对应原图的重要对象。

删除 60%–80% 的次要信息，仅保留 3–7 个主要形块、少量决定性线条和关键明暗关系。允许软硬边变化、轻微错位、边缘中断和局部留白；避免几何拼图、低多边形、矢量图标和普通抽象壁纸。

在下部最安静的留白区加入 {{main_text: 根据画面生成 2–6 字短语}} 与可选的 {{supporting_text: 一句具体而克制的记忆注释}}。不虚构地点、日期和人物身份；文字总面积不超过 5%。整体像当代美术馆出版物，安静、克制、留白充分。
```
